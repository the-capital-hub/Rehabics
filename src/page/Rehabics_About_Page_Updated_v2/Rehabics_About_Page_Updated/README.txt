# Rehabics About Page

## Files
- `AboutPage.jsx`
- `AboutPage.css`

## Integration
1. Put both files in the same `AboutPage` page folder in your React project.
2. Keep the existing image import path `../../assets/docotor.png` if that exact file exists. If the image is named differently in your project, update the import to match the real filename.
3. Install dependencies if they are not already present: `npm install motion react-icons`
4. The component uses React Router links for `/contact` and `/services`; make sure those routes exist.

Content has been updated using the original About page text supplied in chat. Confirm the exact image filename and run the project locally before deploying.
