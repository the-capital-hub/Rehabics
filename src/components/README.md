# Rehabics Remaining Components

These are the components created after Navbar, Hero, and About.

Included:
Services
Conditions
WhyRehabics
Doctor
Testimonials
Locations
Appointment
Footer

Each component has its JSX and CSS file in its own folder.

Install dependencies used by these components:
npm install motion react-icons

Important:
Some links use placeholder routes such as /about, /contact, and /services.
Connect them through React Router before using them in production.
